tacitus, Latin: silent. The relay keeps your record and can't read a word of it.4

The record

Memory a careful historian would keep

Agents don't need another vector database. They need facts with provenance, retrieval that respects the context window, and the ability to write things down without breaking anything.

Provenance, not vibes1

Typed, queryable memories in plain Markdown. Every fact names its source note; contradictions are surfaced, never silently resolved. remember, recall, forget.

Retrieval that fits the window

Search returns ranked snippets under a token budget you set — never whole notes. get_note discloses progressively: outline → frontmatter → full. The wikilink graph is a queryable API. Hybrid lexical + semantic, offline by default.

Write-back you can undo2

Agents propose a changeset, you preview the diff, commits are atomic, and any version reverts.3 Read-only scope forbids mutation outright. Every write lands in the audit log.

recall({ query: "client x deadline", token_budget: 300 })
→ 1 memory, 41 tokens: "Filing deadline is Sep 30, moved from Aug 15."
  source: notes/meetings/2026-07-14.md

propose_changes({ note: "clients/client-x.md", … })
→ changeset cs_91, preview:
  - Deadline: August 15
  + Deadline: September 30 (moved 2026-07-14)

commit_changes({ changeset: "cs_91" })
→ committed as v18 · audit: {origin:"agent", tool:"commit_changes", note:"clients/client-x.md"}

revert({ note: "clients/client-x.md", to_version: 17 })
→ reverted. Nothing an agent does is permanent unless you want it to be.

An abridged session — 25 tools in the native binary, 16 in the npm server, all schema-validated with structured errors.

The silence

Sync where the relay knows nothing

Multi-device CRDT sync through a relay that only ever stores ciphertext. The vault code is the key — everything derives from it, locally, on every device.

# tacitus-mcp sync init → prints your vault code root = argon2id(code, salt v1) vault_key = HKDF(root, "tacitus/v1/vault-key") # XChaCha20-Poly1305 vault_id = HKDF(root, "tacitus/v1/vault-id") # all the relay ever learns
  • No conflicts, no lost edits. Every note is a text CRDT; concurrent edits merge with both sides preserved. Deletes are causal — an unseen edit resurrects the note.
  • Live co-editing. Two devices on the same note merge at keystroke level, end-to-end encrypted, with presence — who's online, which note, typing or not.
  • Self-hostable. The relay is ~one MIT-licensed Rust crate with a Docker image. Or use ours, free while in beta: wss://sync.tacitus.md.
  • No size ceiling. Clients compact the encrypted log themselves — as of v0.23, snapshots chunk, so vaults of any size stay bounded.4

Sources — because claims should have them

  1. Memories are Markdown with YAML frontmatter in .tacitus/memory/ — read them with any editor.
  2. Version snapshots in .tacitus/history/; revert restores any of them atomically.
  3. Every agent write appends to .tacitus/audit.log (JSONL): who, what, when, which tool.
  4. Protocol, threat model, and what a malicious relay can and cannot do: docs/SYNC.md. Short version: it can withhold; it can never read, forge, or splice.
