Documentation

Tacitus is an MCP server that turns a folder of Markdown into long-term memory for AI agents. Start with the guides; these are the references.

  • MCP APIEvery Tacitus MCP tool: arguments, outputs and error codes for agent memory, retrieval under token budgets, revertible write-back, types, tasks and capture.
  • SyncHow Tacitus syncs a Markdown vault between devices with CRDTs through a relay that only ever sees ciphertext — setup, live mode, compaction, quotas.
  • Data formatThe plain files Tacitus keeps in your vault: Markdown notes, typed memories with provenance, version snapshots and the audit log — no database, no lock-in.
  • PluginsBuild on Tacitus: the typed TypeScript SDK, scripts over MCP, and sandboxed WASM plugins that call the same tools with a capability allowlist.
